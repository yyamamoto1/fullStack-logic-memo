# 📓 学習ジャーナル（Learning Journal）

**目的**: 学習の進捗を記録し、知識の定着と振り返りを促進する

---

## 📋 ディレクトリ構成

```
99_learning_journal/
├── README.md           # このファイル
├── templates/          # テンプレート集
│   ├── daily_log.md    # 日次ログテンプレート
│   ├── weekly_review.md # 週次振り返り
│   └── project_todo.md # プロジェクトTODO
├── logs/               # 日次学習ログ
│   └── YYYY-MM-DD.md   # 日付別ログファイル
├── reviews/            # 振り返り
│   └── YYYY-WW.md      # 週次振り返り
└── notes/              # 学習メモ
    └── topic_name.md   # トピック別メモ
```

---

## 🎯 学習ジャーナルの使い方

### 1. 日次ログの作成

毎日の学習終了時に `logs/YYYY-MM-DD.md` を作成します。

```bash
# ファイル作成例
cp templates/daily_log.md logs/2025-10-22.md
```

### 2. 週次振り返りの実施

週末に1週間の振り返りを行い、`reviews/YYYY-WW.md` を作成します。

### 3. 学習メモの蓄積

特定トピックで学んだことを `notes/` に整理します。

## 💡 Tips

### 効果的な学習のために

1. **毎日少しでも続ける**: 1日30分でも継続が大切
2. **アウトプットする**: 学んだことを言語化
3. **振り返りを習慣に**: 週1回は振り返り
4. **疑問を残さない**: わからないことはその日のうちに調べる
5. **実践で確認**: 理論を学んだらコードで確認

### 効果的な振り返り質問

- 今日一番学びになったことは？
- つまずいたところはどこ？なぜ？
- 明日やるべきことは何？
- 今週の目標に対して進捗はどう？
