## 演習一覧

### フロントエンド演習

#### 1. ECサイトフロント
**ディレクトリ**: `01_ecommerce_frontend/`

**概要**: 商品一覧・詳細・カート機能を持つECサイトのフロントエンド

**学習目標**:
- React Router によるルーティング
- 状態管理（Zustand）
- 決済フロー（Stripe）
- レスポンシブデザイン

**技術スタック**: React, TypeScript, Zustand, Tailwind CSS, Stripe

**推奨時間**: 15-20時間

## 演習の進め方

### 1. 準備
```bash
cd 02_intermediate/[演習ディレクトリ]
npm install  # または pip install -r requirements.txt
cp .env.example .env
```

### 2. 要件確認
各演習の `README.md` で詳細要件を確認

### 3. 実装
`starter/` のコードをベースに実装

### 4. テスト
```bash
npm test
npm run test:e2e
```

### 5. 解答確認
`solution/` で模範解答を参照
