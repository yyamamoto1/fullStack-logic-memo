## 1. カスタマージャーニーとは

### 1.1 定義

カスタマージャーニーとは、**顧客が製品・サービスを認知してから、購入し、ファンになるまでの一連の体験**を可視化したものです。

### 1.2 なぜ重要か

- **顧客視点**: 企業視点ではなく顧客視点で考える
- **課題発見**: 各段階での課題やペインポイントを特定
- **施策最適化**: 適切なタイミングで適切な施策を実行
- **チーム共通認識**: 組織全体で顧客体験を共有

## 3. 各ステップの詳細

### Step 1: 発見（Discovery）

> 顧客が製品・サービスの存在を初めて知る段階

#### 顧客の状態
- 課題を認識している/していない
- 解決策を探している/いない
- ブランドを知らない

#### タッチポイント
- 検索エンジン（SEO/SEM）
- SNS（広告/オーガニック）
- 口コミ・レビュー
- プレスリリース
- イベント・セミナー

#### 施策例
```markdown
- SEO対策: 課題に関するキーワードで上位表示
- コンテンツマーケティング: ブログ、ホワイトペーパー
- SNS広告: ターゲット層への認知拡大
- PR活動: メディア掲載、インフルエンサー
```

#### KPI
- インプレッション数
- リーチ数
- ブランド認知度
- 検索ボリューム

---

### Step 2: 検討（Consideration）

> 顧客が製品を比較検討する段階

#### 顧客の状態
- 課題解決の選択肢を調査中
- 複数の製品を比較中
- 機能・価格・評判を評価中

#### タッチポイント
- 公式サイト（LP）
- 製品比較サイト
- レビュー・口コミ
- 無料トライアル
- デモ・説明会

#### 施策例
```markdown
- LP最適化: 価値提案を明確に
- 比較コンテンツ: 競合との差別化ポイント
- 事例紹介: 成功事例、ユーザーの声
- 無料トライアル: 体験してもらう
- FAQ充実: 疑問を解消
```

#### KPI
- サイト訪問数
- ページ滞在時間
- 資料ダウンロード数
- 問い合わせ数
- トライアル登録数

---

### Step 3: 購入（Purchase）

> 顧客が購入・契約を決定する段階

#### 顧客の状態
- 購入意思がある
- 最終確認中
- 不安・疑問が残っている場合も

#### タッチポイント
- 購入画面/決済
- 営業担当（B2B）
- カスタマーサポート
- 契約書・利用規約

#### 施策例
```markdown
- チェックアウト最適化: ステップ数削減、入力簡略化
- 不安解消: 返金保証、セキュリティバッジ
- 限定オファー: 期間限定割引、特典
- カート放棄対策: リマインドメール
- 決済手段: 複数の支払い方法
```

#### KPI
- コンバージョン率（CVR）
- カート放棄率
- 平均注文額（AOV）
- 売上

---

### Step 4: 導入（Onboarding）

> 顧客が製品を使い始める段階

#### 顧客の状態
- 期待と不安が混在
- 使い方を学習中
- 最初の成功体験を求めている

#### タッチポイント
- ウェルカムメール
- 初期設定画面
- チュートリアル
- ヘルプセンター
- カスタマーサクセス

#### 施策例
```markdown
- ウェルカムシーケンス: メール・アプリ内通知
- インタラクティブチュートリアル: 実際に操作しながら学習
- プログレスバー: 設定完了までの進捗表示
- テンプレート提供: すぐに使えるサンプル
- カスタマーサクセス: ハイタッチサポート（B2B）
```

#### KPI
- オンボーディング完了率
- Time to First Value（最初の価値体験までの時間）
- 機能利用率
- 7日/30日リテンション

---

### Step 5: 利用（Usage）

> 顧客が製品を継続的に利用する段階

#### 顧客の状態
- 日常的に使用
- 価値を感じている/いない
- 新機能や活用法を探している

#### タッチポイント
- 製品UI/UX
- メール通知
- プッシュ通知
- ヘルプセンター
- コミュニティ

#### 施策例
```markdown
- 機能発見促進: Tips表示、利用提案
- パーソナライゼーション: 利用パターンに基づく推奨
- 定期的な価値提供: レポート、インサイト
- プロダクトアップデート: 新機能リリース
- ユーザーコミュニティ: 情報交換の場
```

#### KPI
- DAU/MAU
- 機能利用率
- セッション時間
- エンゲージメントスコア

---

### Step 6: 定着（Loyalty）

> 顧客がロイヤルカスタマーになる段階

#### 顧客の状態
- 製品なしでは業務が成り立たない
- 他製品に乗り換える意思がない
- 製品に対して愛着がある

#### タッチポイント
- ロイヤルティプログラム
- VIP特典
- 優先サポート
- ユーザーイベント
- ベータ機能アクセス

#### 施策例
```markdown
- ロイヤルティプログラム: ポイント、ランク制度
- 特別待遇: 優先サポート、限定機能
- コミュニティ活動: ユーザーグループ、イベント
- フィードバック収集: 製品改善への参加
- 感謝の表明: 周年メール、サプライズ特典
```

#### KPI
- 継続率（Retention Rate）
- チャーン率（Churn Rate）
- LTV（顧客生涯価値）
- NPS（Net Promoter Score）

---

### Step 7: 推奨（Advocacy）

> 顧客が製品を他者に推奨する段階

#### 顧客の状態
- 製品の熱狂的なファン
- 自発的に他者に勧めたい
- ブランドアンバサダー

#### タッチポイント
- 紹介プログラム
- レビュー依頼
- SNS共有
- ケーススタディ協力
- ユーザーカンファレンス

#### 施策例
```markdown
- 紹介プログラム: 紹介者・被紹介者への特典
- レビュー依頼: App Store、G2、Trustpilot
- UGC促進: SNS投稿キャンペーン
- 事例取材: 成功事例の公開
- アンバサダープログラム: 公式サポーター制度
```

#### KPI
- NPS
- 紹介率
- レビュー数・評価
- SNSメンション数
- 紹介経由の新規獲得数

## 4. ジャーニーマップの作成

### 4.1 ジャーニーマップテンプレート

```markdown
| 要素 | Step1 発見 | Step2 検討 | Step3 購入 | Step4 導入 | Step5 利用 | Step6 定着 | Step7 推奨 |
|-----|-----------|-----------|-----------|-----------|-----------|-----------|-----------|
| **ユーザー行動** | | | | | | | |
| **タッチポイント** | | | | | | | |
| **思考・感情** | | | | | | | |
| **ペインポイント** | | | | | | | |
| **機会** | | | | | | | |
| **施策** | | | | | | | |
| **KPI** | | | | | | | |
| **担当チーム** | | | | | | | |
```

### 4.2 作成ステップ

1. **ペルソナの確認**: 誰のジャーニーを描くか
2. **ゴール設定**: 最終的にどうなってほしいか
3. **ステップの定義**: 7ステップに沿って整理
4. **現状の把握**: 各ステップでの行動・感情を調査
5. **課題の特定**: ペインポイントを洗い出す
6. **施策の立案**: 課題を解決する施策を設計
7. **KPIの設定**: 測定可能な指標を定義
8. **優先順位付け**: インパクトと実現可能性で判断

## 5. 実践テンプレート

### 5.1 タスク管理SaaSの例

```markdown
## カスタマージャーニーマップ: タスク管理SaaS

### ペルソナ
プロジェクトマネージャー田中（35歳）、10人チームのリーダー

### Step 1: 発見
- **行動**: 「タスク管理 ツール おすすめ」でGoogle検索
- **タッチポイント**: 検索結果、ブログ記事
- **感情**: 😐 現状に不満、良いツールを探したい
- **課題**: 情報が多すぎて選べない
- **施策**: SEO記事「タスク管理ツール比較10選」
- **KPI**: オーガニック流入数

### Step 2: 検討
- **行動**: 3つのツールを比較、無料トライアル登録
- **タッチポイント**: LP、比較表、トライアル
- **感情**: 🤔 どれが自社に合うか悩む
- **課題**: 機能の違いがわかりにくい
- **施策**: インタラクティブ比較ツール、事例動画
- **KPI**: トライアル登録率

### Step 3: 購入
- **行動**: チームプランを契約
- **タッチポイント**: 料金ページ、決済画面
- **感情**: 😊 これで解決できそう！
- **課題**: プラン選びに迷う
- **施策**: プラン診断ツール、チャットサポート
- **KPI**: CVR、ARPU

### Step 4: 導入
- **行動**: 初期設定、チームメンバー招待
- **タッチポイント**: 設定画面、チュートリアル
- **感情**: 😃 早く使いたい
- **課題**: 設定が複雑
- **施策**: 5分で完了するオンボーディング
- **KPI**: 設定完了率、招待率

### Step 5: 利用
- **行動**: 毎日タスク管理、進捗確認
- **タッチポイント**: ダッシュボード、Slack連携
- **感情**: 😐 慣れてきた
- **課題**: 高度な機能を使いこなせない
- **施策**: 週次Tips配信、機能発見UI
- **KPI**: DAU、機能利用率

### Step 6: 定着
- **行動**: チーム全員が日常的に利用
- **タッチポイント**: メール、コミュニティ
- **感情**: 😍 もう手放せない
- **課題**: マンネリ化
- **施策**: 新機能優先アクセス、ユーザー会
- **KPI**: 継続率、NPS

### Step 7: 推奨
- **行動**: 同僚に紹介、レビュー投稿
- **タッチポイント**: 紹介プログラム、レビューサイト
- **感情**: 😍 みんなにも使ってほしい
- **課題**: 紹介するきっかけがない
- **施策**: 紹介特典、レビューキャンペーン
- **KPI**: 紹介数、レビュー数
```

## まとめ

カスタマージャーニー7ステップを理解することで:

1. **顧客視点で設計できる**: 企業都合ではなく顧客体験を優先
2. **課題を可視化できる**: どこで離脱しているかがわかる
3. **適切な施策を打てる**: 各段階に合った施策を実行
4. **組織で共有できる**: チーム全体で顧客理解を深める
